Personal Fitness OS

iPhone-first operating system for following an existing training program while managing injury recovery, body composition, and health signals from Apple Health, WHOOP, and manual check-ins.

Mobile Preview

Install Expo Go on your iPhone. On your Mac, run cd /Users/codyplofker/Desktop/01-Projects/personal-fitness-os and then npm start. Scan the QR code that appears in the terminal. Your phone and Mac should be on the same Wi-Fi network.

What Is Built

Today

Readiness score, pain gate, daily recommendation, and planned session.

Program

Weekly training shell designed around your existing program.

Recovery

HRV, sleep, resting HR, steps, soreness, and adjustment rules.

Body

Body-composition trend and no-calorie-counting habit anchors.

MVP Decisions

Single user iPhone first Existing program No calorie counting No Apple Health writes

Integration Reality

  • Apple Health requires a native iOS HealthKit bridge.
  • A pure web app cannot directly read Apple Health data.
  • WHOOP requires a developer app, OAuth client, and read scopes.
  • The current prototype uses mock data until credentials and native modules are added.

Initial Data Sources

  • Apple Health: HRV, sleep analysis, steps, resting heart rate, body mass.
  • WHOOP: recovery, sleep, cycles / strain, workouts.
  • Manual: pain, soreness, energy, habits, measurements, notes.
