Critical config note

ANTHROPIC_API_KEY in .env.local is currently blank. This silently disables:

  • subjectPlacement.detectSubjects() → pickAnchor() falls back to "top" anchor only
  • The Vision-based path of the new auto-iterate validation (heuristic fallback covers most cases but is less accurate)

To unlock the full Patch 6 behavior: set ANTHROPIC_API_KEY=sk-... in .env.local. The c1 1×1 v4 failure (stick still oversized) would have been caught by Vision but slipped past the heuristic.
