  9. Press / trust bar — logos load from theme file, not text fallbacks.
  10. Ship-readiness — sign off in #landingpages thread before template flip.

How the template swap works (Rebecca)

Once a preview is QA-approved, the swap is a 2-click change in Shopify admin — no ad URL changes, no redirects, no downtime.

  • Open the live page (Admin link in the table above)
  • In the right-rail Theme template dropdown, change from the current replo.{uuid} to the new CCLP template (e.g. miracle-balm-the-secret-v2)
  • Save. The live URL now renders the CCLP template instantly.
  • Revert anytime by switching back to the Replo template — no data loss.
