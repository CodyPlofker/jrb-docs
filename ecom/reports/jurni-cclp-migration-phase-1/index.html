Notes for review

  1. 1:1 image match. Every section image on every CCLP page was uploaded from the matching Jurni position to Shopify Files. Hero, 5 (or 3) reasons, Bobbi quote — all match the originals.
  2. MMB V1 vs V2 share identical body content. Only the hero headline differs ("5 Ways… Transform" vs "5 Reasons… Talking"). That's the A/B test Jurni was running. In Shopify, this could collapse to one page + Intelligems hero test instead of two pages.
  3. Multi-Product Generic isn't a numbered listicle — it's a multi-product trust page. Used cclp-reason-row sections with empty number labels for the alternating content rows. Hero, main product, 3 content rows, FAQ, final CTA all render.
  4. Known CCLP template limitations (consistent across all 6, addressable with section enhancements): no review photos in cclp-testimonial-cards, no closing-CTA image in cclp-cta-band. Both are template-level — Jurni had these, CCLP doesn't yet.
  5. If iframes don't render some sites block embedding via X-Frame-Options. Click the "Open ↗" buttons at the top of each row to view in a new tab.
