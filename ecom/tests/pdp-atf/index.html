1 — The Problem

JRB's PDP above-the-fold is doing too much.

The same Miracle Balm PDP gets described by prospects as both "everything increased my interest more and more" AND "a little too much information... overwhelming." The page suffers an information depth paradox — depth is helping researchers but punishing scanners. Above the fold, the cost of clutter is higher than the value of comprehensiveness.

Counts from a live audit of jonesroadbeauty.com/products/miracle-balm (mobile):

The directional bet is that JRB's ATF is structurally over-loaded. Reducing decisions and re-prioritizing what's surfaced should lift RPS — every JRB precedent test in this direction has won.

4 — Test Design

Convertibles cumulative stacking. 4 cells. One change per step.

Per the Convertibles Needle Movers framework: "always multivariate with 1 variable different." Each variant adds exactly one change on top of the previous. V3 may look materially different from Control, but every change is independently attributable.

Control = Current PDP ATF (as-is)
V1      = Control with ATF clutter REMOVED (decision-load reduction)
V2      = V1 + multi-use proposition surfaced into the ATF
V3      = V2 + single review snippet under stars

Why this stacking order: Removal first (foundation, highest-confidence move proven by JRB31). Multi-use second (once the ATF has breathing room, the highest-leverage missing signal can be added without re-cluttering). Review snippet third (third-party trust signal goes on top of the now-clean foundation, fixes the brand-site review-skepticism gap).

6 — Measurement & Targeting

Blanket roll, segmented analysis.

Targeting: Blanket — all PDP traffic. No segment is anticipated to suffer (we're removing clutter that affects everyone). Backend analysis filters by Quadrant of Traffic per BDW Ch 16.

Quadrant analysis (mandatory): Per Dylan Ander, every test result must be filtered through {New, Returning} × {Mobile, Desktop} before declaring a winner. A flat-overall test can hide a +20% First-Time Mobile lift.

Sample size + runtime

JRB PDP traffic baseline: ~80K sessions/week to MMB-class PDPs. For a 4-cell test detecting 5% RPS lift at 95% significance, 80% power: ~14 days to significance. Recommended runtime: 3 weeks minimum to capture two complete shopping cycles (weekday × weekend × payday).

Decision tree

If V3 wins overall: ship V3 to all PDP variant templates. All three changes validated.

If V2 wins but V3 doesn't: ship V2; investigate why review snippet didn't move the needle (curation, placement, attribution format).

If only V1 wins: ship V1; defer multi-use icons to a separate isolated test.

If only Quadrant wins (e.g. First-Time Mobile +X%, Returning Desktop flat): ship as a Quadrant-targeted Intelligems audience.

7 — Implementation Notes

Built on Intelligems. No theme changes.

  • Serve via Intelligems — no Liquid changes until winner declared. hide_section: true on every CCIG variant of the live theme per JRB convention.
  • All variants are CSS/DOM transforms of existing PDP markup. V1 is pure rearrangement (no new component). V2 needs one new .multi-use module. V3 needs Junip data pull or hardcoded curated review set.
  • Mobile-first: 480×800 viewport per BDW. Desktop benefits responsively.
  • Sticky ATC kept across all variants — separate proven pattern, not under test.
  • Run on all variant-bearing PDPs: Miracle Balm, Mini Miracle Balm, JETM, WTF, Best Eyeshadow, Best Pencil, Cool Gel Bronzer, etc. ATF reorganization is template-universal.

9 — The Big Idea

Above the fold is a decision-cost budget.

Every button, chip, swatch, and tool entry-point above the fold is a unit of cognitive load the visitor pays before they're allowed to engage with the product. The current PDP spends that budget on "options" (15 shades, 5 categories, 3 packs, 2 shade tools) and runs out before delivering the highest-leverage signals (multi-use, social proof, texture reassurance). This test reallocates that budget — strip cost out of the option-presentation, spend it on signal instead.

Cody's intuition that "cleaner will do better" is the right directional bet. The data backs it. JRB precedent confirms it. Every competitor proves it.
