Top speed wins from the Claude and Codex audit.

The rebuilt Shopify theme is not the problem. Both auditors found the biggest speed drag in the weight around it: redundant third-party scripts, font loading, Replo leftovers, raw assets, and global libraries.

Tier-1 wins

Highest-confidence speed impact.

Confirmed by both

Third-party script redundancy

Two A/B-testing stacks plus a third PDQ test path: Intelligems, Convert, and PDQ. Two heatmap/session paths need verification: heatmap.com plus possible Clarity/GTM/app embed firing. Intelligems is explicitly render-blocking; Convert/PDQ are not async everywhere.

Confirmed by both

Font-display, preload, Typekit preconnect

Canela, Ringside, Base Mono, and Geogrotesque have no font-display. Canela is not preloaded for above-fold headings. ArticulatCF uses Typekit without a preconnect, and there are repeated/legacy declarations.

Confirmed by both

Roughly 81MB of Replo cruft

The export includes 448 Replo chunk snippets and 162 Replo page templates. Unused source weight bloats deploys and code review; live Replo pages likely carry heavy HTML, CSS, and runtime cost. Codex also found Replo head rendering globally.

Confirmed by both

4.5MB raw asset image bypassing CDN transforms

The quiz card complexion image is a 4.5MB theme asset that can render into a 112-by-112 card via asset_url. Theme assets do not get the same responsive image pipeline as Shopify image objects.

Execution split

What can move now versus what needs a PR.

Live firing inventory across Intelligems, Convert, PDQ, heatmap.com, Clarity, GTM, app embeds, Web Pixels, Triple Whale, Northbeam, Postpilot, Rokt, Loop, SMS affiliate, Junip, and Replo. Third-party script loading changes in layout and snippets: one CRO blocker max, defer nonessential scripts, unconditional async/defer for kept scripts.

Media inventory and replacement prep: find pages using the 4.5MB quiz image and theme MP4s; prepare optimized Shopify Files assets. Raw media PR: update cclp-quiz-hero and related section rendering to use Shopify image_url, srcset, sizes, width, and height.
Measurement pass on PDP, collection, quiz/CCLP, and one live Replo page using Lighthouse/WebPageTest/Shopify Web Performance. Swiper PR: remove global include, standardize one version, section-scope loader, remove jsDelivr fallback/version drift.
Template JSON-only cleanup if assignments are confirmed unused, reversible, and do not touch shared theme files. Cart/GWP/settings lazy-load PR, Intelligems payload PR, PDP mini-builder lazy-load PR, and staged Replo deletion/gating PRs.

Guardrail: shared theme files such as custom-fonts.liquid, layout/theme.liquid, sections, snippets, and assets should not be pushed directly to live. Those go through the PR-to-develop flow. Template JSONs are the only items that can be direct if the change is confirmed safe and reversible.

Recommended order

Run the work in this order.

  1. Inventory live third-party firing and remove/disable obvious duplicates with owners aligned.
  2. Open a font PR for font-display, Canela preload, Typekit preconnect or self-hosting, and format cleanup.
  3. Replace the 4.5MB quiz card image and move photographic fallbacks to responsive Shopify image objects.
  4. Remove global Swiper loading and standardize one section-scoped version.
  5. Lazy-load cart/GWP/settings payload and trim Intelligems product data to active experiment needs.
  6. Stage Replo cleanup behind traffic inventory, rebuilding high-traffic survivors as native sections before deletion.
