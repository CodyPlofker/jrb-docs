What changes on scroll

The header becomes the purchase moment.

The regular site navigation is available while the customer is still in the primary buy box. After that section scrolls away, the same fixed header space turns into product name, variant context, price, and Add to Cart. No new sticky layer is added.

Guardrail one: no content coverage −

Unlike a bottom sticky bar or a second top bar, this pattern does not cover the page. It uses the space already occupied by the nav.

Guardrail two: show product context −

The sticky state should include product name, selected shade or variant, price, and a clear purchase action.

Why test it

CTA persistence without the cramped-page feeling.

This is meant to preserve the CRO upside of a sticky Add to Cart while avoiding the main downside Cody flagged: hiding valuable PDP education. On mobile, the key question is whether top nav replacement beats bottom sticky CTA because it avoids covering the reading area.

Avoid

Normal nav plus extra sticky ATC. This stacks chrome and can steal 140–150px of vertical space before customers see product education.

Recommended test

Header transforms into the PDP CTA after the original buy box scrolls away. Same sticky footprint, more usable content space.
