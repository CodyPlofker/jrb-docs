  • Added a dev-gated custom BIS setting: waitlist_custom_bis_enabled.

  • When enabled, PDP waitlist submissions post to the custom API instead of the legacy AMP path.

API Preview

  • Accepts PDP subscribe requests and creates Klaviyo profile/list/BIS records.
  • Registers a preview-only Shopify INVENTORY_LEVELS_UPDATE webhook.
  • Verifies Shopify webhook HMAC using raw request body handling.
  • Discovers online-fulfillment locations from Shopify unless explicitly configured.
  • Updates Klaviyo custom catalog inventory on inventory changes.
  • Upserts missing Klaviyo custom catalog item/variant records when Klaviyo returns missing-variant errors.
  • Stores inventory state and logs restock_threshold_crossed events.
